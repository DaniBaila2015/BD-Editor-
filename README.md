# 🎨 Criador de Banda Desenhada

Esta é uma aplicação web **100% gratuita** e interativa criada para desenhar, pintar e construir histórias de banda desenhada diretamente no navegador. Funciona tanto em computadores como em dispositivos móveis (telemóveis e tablets).

---

## 🚀 Funcionalidades

- **✏️ Desenho Livre:** Pinceis personalizáveis para desenhar os teus personagens.
- **🎨 Paleta de Cores & Tamanhos:** Escolhe qualquer cor e ajusta a espessura do traço.
- **🔤 Ferramenta de Texto:** Escreve as falas nos balões com tipos de letra estilo BD (como *Impact* ou *Comic Sans*).
- **📥 Descarregar PNG:** Guarda a tua banda desenhada diretamente no teu dispositivo como uma imagem.
- **💾 Guardar & Carregar Local:** Guarda o teu progresso no próprio navegador para não perderes o trabalho se fechares a página.
- **🖼️ Abrir Ficheiro:** Importa uma imagem ou um desenho antigo do teu dispositivo para continuares a pintar.
- **🗑️ Limpar Tela:** Apaga tudo instantaneamente com um clique para começar de novo.

---

## 🛠️ Como Usar

1. **Desenhar:** Clica em "✏️ Desenhar", escolhe a cor e o tamanho do pincel na barra de ferramentas e usa o rato (ou o dedo no telemóvel) para criar a tua arte.
2. **Escrever:** Clica em "🔤 Texto", clica no local do desenho onde queres escrever, digita a fala e clica fora (ou prime *Enter*) para aplicar.
3. **Guardar o Trabalho:** 
   - Usa o botão **Guardar Local** para manter o desenho na memória do navegador.
   - Usa o botão **Descarregar PNG** para baixar o ficheiro final.

---

## 💻 Como Executar Localmente

Se quiseres rodar este projeto no teu computador sem internet:
1. Descarrega o ficheiro `index.html`.
2. Dá um duplo clique no ficheiro. Ele vai abrir instantaneamente em qualquer navegador (Chrome, Edge, Safari, Firefox).

---

## 📝 Tecnologias Utilizadas

- **HTML5** (Estrutura e a tag `<canvas>` para a área de desenho)
- **CSS3** (Estilização moderna e barra de ferramentas responsiva)
- **JavaScript** (Lógica do desenho, escrita de texto e gestão de ficheiros)
